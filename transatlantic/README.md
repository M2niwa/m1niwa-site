# 横渡大西洋 · Transatlantic 1932

一款浏览器里的合作小游戏：1932 年，从纽芬兰起飞，独自或与搭档一起把飞机修修补补地开到爱尔兰。
五架可选座机，单人、同屏双人、局域网联机，支持键盘、手柄和手机触屏。

## 运行

需要先装好 [Node.js](https://nodejs.org/)（12 以上即可，不用装任何依赖）。

- **Windows**：双击 `start.bat`，浏览器会自动打开。
- **其他系统**：在这个文件夹里运行 `node server.js`，再用浏览器打开 http://localhost:8765 。

换端口：先设置环境变量 `PORT`，例如 `PORT=9000 node server.js`。

> 第一次打开需要联网：three.js 和标题字体是从公共 CDN 加载的。
> 直接双击 `index.html` 也能玩，但会退回程序合成的音效和程序贴图，也不能联机。

## 操作

| | 移动 | 互动 | 拾取 / 放下 | 冲刺 | 暂停 |
|---|---|---|---|---|---|
| 键盘（单人 / 一号） | W A S D | E | Q | Shift | Esc |
| 键盘（同屏二号） | 方向键 | Enter | / | 右 Shift | Esc |
| 手柄 | 左摇杆 / 十字键 | A | X | B | Start |
| 触屏 | 左半屏拖动 | 互动 | 拾取 | 冲刺 | 左上角 Ⅱ |

坐在驾驶座上时：上 / 下 = 爬升 / 俯冲，左 / 右 = 修正航向，互动键 = 离座。
机库里：拖动旋转镜头、滚轮缩放；`V`（手柄 Select）切换画风；`Tab`（手柄 Y）切换机组编制。

## 局域网联机

1. 一台电脑运行服务器（上面的"运行"），进机库选「局域网联机」→「开房 · 我当机长」。
2. 面板上会显示一个链接，队友在**同一网络**的电脑或手机浏览器里打开它，进机库后自动加入。
3. 机长选座机、点起飞。队友可以中途加入。

连不上时先检查：两台设备是否在同一个 Wi-Fi / 网段；主机的防火墙是否放行了 8765 端口；
面板上列出的地址是否是主机在这个网络里的地址（装了虚拟机或代理软件时，可能要换成另一个）。

## 手机

横屏游玩，竖着拿会提示横过来。手机既可以单人玩，也可以当联机的队友。
帧率跟不上时游戏会自动降低渲染分辨率。

## 调试用的地址参数

`?ac=0..4` 选机型 · `?mode=2` 同屏双人 · `?hangar=1` 直接进机库 · `?auto=1` 直接起飞 · `?p=0.5` 从航程一半开始 ·
`?style=0|1` 画风 · `?notex=1` 关掉照片贴图 · `?nomerge=1` 关掉网格合并 · `?join=1` 进机库就加入联机

## 文件

```
index.html      页面与界面样式

js/core.js      工具函数、输入（键盘 / 手柄 / 触屏）、音频
js/gfx.js       渲染：天空、海洋、云、陆地、粒子、后期
js/parts.js     程序化建模零件库与材质
js/aircraft.js  五架飞机
js/scenery.js   机场布景与途中景物
js/game.js      玩法、界面、联机
audio/          风、雨、雷、引擎的录音（来源见 audio/CREDITS.md）
tex/            照片贴图（来源见 tex/CREDITS.md）
```
